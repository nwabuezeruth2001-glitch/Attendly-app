# Attendly Frontend

Responsive frontend for the Attendly attendance management UI/UX supplied by the user.

Stack: plain HTML5 + CSS3 + vanilla JavaScript. No framework is required.

## Run
Open `login.html` directly in a browser, or serve the folder with any static server.

## Pages
- login.html
- register.html
- dashboard.html
- students.html
- add-student.html
- attendance.html
- attendance-history.html
- reports.html
- student-report.html
- settings.html
- loading.html
- empty.html
- error.html

Shared files:
- assets/style.css
- assets/app.js

## Backend integration
Replace the demo actions in `assets/app.js` with fetch/axios calls to your API. The HTML forms and tables already have IDs/classes that make wiring them to a backend straightforward.
